# 🐱 CatHome

[HammyHome](https://hammyhome.com/)의 고양이 버전 — 브라우저에서 가상 고양이를 입양해 돌보고, 방을 원하는 대로 꾸미고, 장난감을 던져주며 노는 육성 시뮬레이션입니다.

`index.html` + `CAT.webp` 두 파일로 동작합니다. 빌드 도구도 외부 라이브러리도 없습니다.
**고양이는 실제 사진(`CAT.webp`)을 머리·몸통·꼬리·네 다리로 잘라 관절 리그로 움직입니다.** 사진 자세를 기준으로 관절을 조금씩만 돌리고, 잡으면 늘어나고 털이 딸려 올라옵니다. 방·가구·장난감은 Canvas 2D 벡터 드로잉이지만, 사진 속 고양이와 톤이 맞도록 실사풍으로 그립니다 — 재질별 그러데이션과 미세 입자(노이즈), 부드러운 접지 그림자, 창에서 들어와 바닥에 창살 무늬를 그리는 햇빛까지. 벽·마루와 정적인 가구는 오프스크린 캔버스에 한 번만 그려 두고 재사용해 매 프레임 비용을 줄입니다.

## 실행

`index.html`을 브라우저로 열면 끝입니다. (사진과 같은 폴더에 있어야 합니다. 사진을 못 찾으면 자동으로 벡터 고양이로 대체됩니다.)

## 게임 방법

### 1. 입양
스타터 고양이 5종(치즈 / 턱시도 / 삼색 / 회색 태비 / 샴) 중 하나를 고르고 이름을 지어줍니다. 다섯 마리 모두 같은 사진에서 색 보정(`ctx.filter` + multiply 합성)으로 구워 낸 변형입니다. 품종마다 식욕·활동량·애교 수치가 달라서 행동 패턴이 조금씩 다릅니다.

### 2. 돌보기

| 버튼 | 하는 일 |
|---|---|
| 🍚 밥주기 | 밥그릇을 채웁니다. 배고프면 고양이가 알아서 와서 먹습니다 |
| 💧 물주기 | 물그릇을 채웁니다 |
| 🪶 놀아주기 | 낚싯대 모드. 마우스(터치)를 따라 고양이가 뛰어다닙니다 |
| 🤚 쓰다듬기 | 행복 상승 + 골골송. 고양이를 직접 클릭해도 됩니다 |
| 🧹 화장실 | 모래를 갈아줍니다. 방치하면 냄새가 나고 청결·행복이 빨리 떨어집니다 |
| 💡 불 끄기 | 밤이 되어 고양이가 잠자리를 찾아가 자고 기력을 빠르게 회복합니다 |
| 🛋️ 꾸미기 | 인테리어 편집 모드로 들어갑니다 |

밥그릇·물그릇·화장실은 방 안에서 직접 클릭해도 동작합니다.

### 3. 인테리어 꾸미기 🛋️

**가구 25종**을 자유롭게 배치할 수 있습니다. 방에는 최대 42개까지 놓을 수 있습니다.

- **팔레트에서 아이템을 누르면** 방에 놓이고, **드래그해서** 원하는 자리로 옮깁니다
- 바닥 가구는 앞뒤(깊이)로도 옮길 수 있어서 **앞에 놓은 물건이 고양이를 가립니다**
- 벽 아이템(액자·선반·시계)은 벽 어디든 붙일 수 있습니다
- `↔ 뒤집기`로 좌우 반전, `🗑 치우기`(또는 Delete 키)로 제거, `완료`(또는 Esc)로 편집 종료
- 고양이가 올라가 있는 가구를 옮기면 고양이도 같이 따라옵니다

| 종류 | 가구 |
|---|---|
| 필수 | 밥그릇, 물그릇, 정수기, 화장실 |
| 쉼터 | 방석, 캣하우스, 캣해먹, 소파, 종이상자, 캣터널 |
| 놀이 | 캣타워, 스크래처, 캣휠, 캣닢, 어항 |
| 장식 | 러그, 화분, 플로어 램프, 액자, 벽 선반, 벽 발판, 벽시계 |
| 장난감 | 공, 쥐인형, 깃털 장난감 |

**가구를 치우면 고양이가 그 행동을 못 합니다.** 밥그릇을 치우면 밥을 줄 수 없고, 스크래처가 없으면 발톱을 갈지 않습니다. 반대로 캣휠을 놓아주면 신나게 달리기 시작합니다.

### 4. 고양이와 가구 상호작용

고양이는 방에 놓인 가구를 스스로 찾아가 사용합니다.

- **캣타워 · 소파 · 벽 선반 · 벽 발판** — 포물선을 그리며 **뛰어올라가** 앉아서 방을 구경하고, 가끔 그대로 존다
- **벽 발판**은 여러 개를 계단처럼 이어 붙여 **캣워크**를 만들 수 있습니다
- **종이상자 · 캣터널 · 캣하우스** — 안에 들어가 웅크립니다(등만 빼꼼 보입니다)
- **스크래처 · 캣타워 기둥** — 두 앞발로 긁습니다. 청결·행복 상승
- **캣휠** — 안에서 달립니다. 바퀴가 실제로 돌고 기력이 빠르게 소모됩니다
- **방석 · 소파 · 캣해먹** — 동그랗게 말고 잠듭니다. 해먹은 천이 실제로 축 처집니다
- **캣닢** — 옆에서 **몸을 비틀며 뒹굽니다**. 하트가 튀고 행복이 크게 오릅니다
- **어항** — 앞에 앉아 헤엄치는 물고기를 구경하며 **캭캭거립니다**. 행복이 오르고 기력도 조금 회복
- **정수기** — 물이 계속 흐릅니다. 물그릇 대신 여기서 마셔도 됩니다
- **플로어 램프** — 불을 끄면 램프만 켜 둔 것처럼 방을 따뜻하게 밝힙니다
- 높은 곳에 있을 때는 **먼저 뛰어내린 뒤** 다음 행동을 합니다

### 5. 고양이 잡기 · 던지기 🤲

고양이 자체가 물리 객체입니다.

- **톡 누르면** 쓰다듬기, **꾹 눌러 끌면** 번쩍 들어 올립니다 (누른 채 0.2초만 기다려도 잡힙니다)
- **집은 자리의 털이 손가락 사이로 딸려 올라오고**, 그 주변에 눌린 자국과 주름이 생깁니다
- **어디를 집었는지가 그대로 반영됩니다.** 등을 잡으면 배를 아래로 늘어뜨리고, **꼬리를 잡으면 거꾸로 매달립니다** (집은 점 아래로 무게중심이 오도록 각도를 계산)
- 몸이 손을 늦게 따라오며 **진자처럼 흔들리고**, 네 발과 꼬리를 버둥거립니다
- **빠르게 휘두르면 몸이 쭉 늘어나고**, 멈추면 스프링처럼 통통 튀며 원래대로 돌아옵니다. 세게 휘두르면 잔상 선이 그려집니다
- 3초 넘게 들고 있으면 💢 표시와 함께 싫어하며 버둥거립니다 ("내려줘!") — 행복도가 떨어집니다
- 반대로 **목덜미를 살살 잡고 가만히 있으면** 새끼고양이처럼 **축 늘어져서** 골골거립니다 (행복도가 오릅니다)
- **놓으면 그 순간의 속도로 날아갑니다.** 공중에서 회전하다가 착지 직전에 **자세를 바로잡고 발로 착지**합니다
- 착지 순간 몸이 납작하게 **찌그러졌다가 되돌아오고**, 세게 떨어지면 한 번 더 튀어 오릅니다. 벽에 부딪혀도 튕깁니다
- 살며시 내려놓으면 그냥 사뿐히 착지합니다
- **던진 방향이 앞뒤(깊이)로도 반영됩니다.** 아래로 던지면 방 앞쪽에 떨어지고, 위로 띄우면 원래 자리로 돌아옵니다. 바닥 가까이에서 천천히 끌면 그 자리로 옮겨집니다 (장난감도 똑같이 동작합니다)
- **소파·캣타워·방석·종이상자 위로 던지면 그 자리에 착지해서** 바로 앉거나 잠들거나 숨습니다

### 6. 물리 장난감 ⚽

공과 쥐인형에는 **중력·반발·마찰·회전**이 적용됩니다.

- **집어서 던지면** 던진 속도 그대로 날아가 포물선을 그리고, 바닥에서 튀어 구르다 멈춥니다
- 벽과 **가구에 부딪히면 튕겨 나오고**, 소파나 상자 **위에 올라가 얹히기도** 합니다
- 굴러가는 장난감을 보면 고양이가 **쫓아가서 앞발로 칩니다**. 맞은 장난감은 다시 날아갑니다
- 세게 던질수록 고양이가 멀리서도 반응합니다
- **놓는 자리는 앞뒤(깊이)까지 자유입니다.** 꾸미기 모드에서 끌어다 놓으면 그 자리에 자기 바닥선이 생겨서, 벽 앞이든 방 맨 앞이든 그 줄에서 굴러다니고 고양이도 그 자리로 찾아갑니다

### 7. 움직임과 분위기

- 고양이는 **관절이 하나씩 따로 움직입니다.** 머리·꼬리 3마디·네 다리(각 2마디)가 각자 회전하고, 관절 각도가 스프링으로 목표를 따라가서 자세가 바뀔 때 뚝 끊기지 않습니다
- 기준 자세는 **사진 그대로**이고, 거기서 관절을 **최대 20° 남짓만** 돌립니다. 사진을 표준 자세로 억지로 펴면 조각이 뒤틀리기 때문입니다. 걸음 위상은 시간이 아니라 **이동한 거리**로 진행합니다
- 방향을 바꿀 때는 즉시 뒤집히지 않고 **몸이 한 번 얇아졌다가 반대로 넓어지며** 돌아섭니다. 반대편 다리는 조금 어둡게 그려 앞뒤를 구분합니다
- 그림자는 **몸통 아래 부드러운 그라데이션 + 발끝마다 접지 그림자**로, 발이 뜨면 옅어집니다
- 방은 사진과 톤을 맞춰 채도를 낮추고, **창에서 들어오는 햇빛 웅덩이 · 벽과 바닥이 만나는 그늘 · 가장자리 비네팅**을 얹었습니다

### 8. 스탯
포만감 / 수분 / 행복 / 청결 / 기력 5종이 실시간으로 줄어듭니다.
**기력**은 자는 동안 5분이면 가득 차고(불을 끄면 계속 잡니다), 앉아 있거나 상자·해먹에서 쉬거나 어항을 구경하는 동안에도 조금씩 회복됩니다. 캣휠을 달리거나 낚싯대로 놀아 줄 때만 눈에 띄게 줄어듭니다. 방 앞쪽으로 나올수록 고양이가 조금 크게 그려져 원근감이 생깁니다.

## 저장

진행 상황(스탯·가구 배치·장난감 위치)은 `localStorage`(키: `cathome.save.v1`)에 15초마다 자동 저장됩니다. 접속하지 않은 동안에도 시간이 흘러 스탯이 줄지만(최대 12시간까지 반영, 소모 속도는 35%로 완화) 고양이가 죽지는 않습니다. 상단 ↺ 버튼으로 처음부터 다시 시작할 수 있습니다.

## 구조 (index.html 한 파일)

| 영역 | 내용 |
|---|---|
| 상수 / 가구 카탈로그 | 방 좌표계, 스탯 감소 속도, 품종 팔레트, `FURN` 가구 정의(크기·역할·그리기 함수) |
| 사운드 | 전부 WebAudio 합성이고 외부 음원이 없다. **울음소리**는 성대 + 포먼트(입 모양) 모델로 야옹·냥·조르기·트릴·하악질·성난 울음·채터링·골골 8종을 만들고, 상황과 기분에 따라 `catVoice(mood)`가 골라 낸다. **생활 소음**은 노이즈 + 짧은 공진 조합(발진음 없음)으로 씹기·핥기·긁기·사료 붓기·물 따르기·모래 파기·착지·장난감 부딪힘을 만든다 |
| 세이브 / 로드 | localStorage 직렬화, 구버전 세이브 보정, 오프라인 시간 반영 |
| 고양이 AI | 상태 기계 23종(캣닢 뒹굴기 · 어항 구경 포함) + `decideNext()` 가중치 행동 선택, `useFurniture()` 가구 사용, `jumpTo()` 포물선 점프 |
| 고양이 물리 | `held`/`fall`/`land` 상태, 잡은 손 추종 + 속도 기록 → 던지기, 중력·반발·벽 튕김, `landingY()` 가구 표면 착지(직전 프레임 기준이라 통과하지 않음), 공중 회전 후 자세 복원 |
| 늘어남·찌그러짐 | `squash()` + `springScale()` 스프링 스케일(sx/sy)을 발 위치 기준으로 적용. 그림자는 변형과 무관하게 바닥에 고정 |
| 장난감 물리 | 중력 적분, 바닥·벽 반사, AABB 가구 충돌(가장 얕은 축으로 밀어내기), 구름 회전 |
| 방 그리기 | 벽·창문(낮/밤)·원목 마루 + 가구 25종 개별 드로잉 |
| 고양이 그리기 (사진) | `CAT.webp`(알파 있는 550x452 사진)를 실루엣 스캔으로 측정해 **13조각**(머리 / 몸통 / 꼬리 3마디 / 네 다리 각 2마디)으로 자른다. 마스크는 캡슐·타원의 합차로 정의하고 경계는 blur로 부드럽게 해서 관절이 벌어져도 이음새가 보이지 않는다. 품종별 색보정은 자르기 전에 굽는다 |
| 관절 리그 | 몸통을 루트로 한 뼈대에 조각을 물리고, 관절 각도는 부위별로 다른 속도의 스프링으로 목표를 따라가서 상태가 바뀌어도 뚝 끊기지 않는다. **기준 자세가 사진 그대로**이고 회전 폭을 20° 안팎으로 제한하는 것이 핵심 — IK로 표준 자세를 만들려 하면 관절이 60° 넘게 돌아가 사진 조각이 뒤틀린다. 걸음은 대각선 두 발씩 짝지어 흔들고, 위상은 이동 거리로 진행한다 |
| 고양이 그리기 (대체) | 사진이 없을 때 쓰는 벡터 리그 — 서기 / 앉기 / 말려 자기 3종, 품종별 무늬(태비·턱시도·삼색·샴 포인트) |
| 렌더 | 벽 → 바닥 장식 → (가구·고양이·장난감) **깊이(y) 정렬** 순으로 그린 뒤, 창빛·바닥 그늘·비네팅을 얹어 사진과 톤을 맞춘다 |
| UI | 스탯 바, 액션 버튼, 꾸미기 팔레트(썸네일도 같은 드로잉 코드 재사용), 입양 화면 |
